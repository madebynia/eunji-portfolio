# UI Design Workflow

## 순서

현재 화면/코드 분석
→ DESIGN.md 확인
→ 기존 컴포넌트 확인
→ 필요할 때만 외부 레퍼런스 조사
→ 제품 스타일에 맞게 재해석
→ 구현
→ responsive / accessibility / motion QA

## 참고 소스

- Refero / awesome-design-md: style direction
- 21st.dev: component pattern
- Component Gallery: UX structure
- Kinetics: motion reference
- Impeccable: critique / polish / distill

사용자가 모든 후보를 직접 찾을 필요는 없다.
AI가 후보를 좁혀 제안할 수 있지만, 전체 visual direction을 바꾸는 결정은 적용 전에 보여준다.
